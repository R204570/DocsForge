Home

Every document is a card. Ask for one and it gets painted into the stack.

Give it a URL. It works out what kind of source that URL is, extracts it, and hands you Markdown a language model can actually read — so the model stops guessing about a library it was never trained on.

What it reads

llms.txtThe LLM-native docs standard, passed straight through.
openapiSwagger or OpenAPI, JSON or YAML, rendered as endpoint tables.
sitemapEvery page listed in a sitemap.xml, indexes included.
githubA repo's README plus everything under docs/.
htmlA docs site, with nav, footers and chrome stripped out.
raw_textMarkdown or plain text, cleaned up.

Cards are yours to edit before you keep them. Edit This Card turns the document back into a text field, and the download takes your version, not the model's.
