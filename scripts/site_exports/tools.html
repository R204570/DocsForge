REFERENCE

Twelve tools, defined once.

Every tool is defined exactly once and served identically over MCP. Results handed to a model are capped at 60k characters with an explicit truncation marker.

LEARN
learn_technology
name version ecosystem max_pages js intent corpora strict

Learns a library from its name alone — no URL. Resolves, verifies, harvests, stores.

Returns: Page count, characters, strategy, and a completeness verdict.

harvest_docs
url name max_pages js scope version

Learns a whole technology from one starting URL. Unlimited by default.

Returns: A summary; read the content back with read_knowledge_base.

find_docs
name ecosystem

Where a name resolves to, with the evidence. Harvests nothing.

Returns: Candidates and how often each page names the package.

scan_project
path unknown_only

Reads a project's dependency manifests: libraries, versions, and which are already documented.

Returns: A dependency table with documented / undocumented status.

EXTRACT
fetch_docs
url crawl max_pages js force

Extracts any documentation URL to clean Markdown. Auto-detects llms.txt, OpenAPI, sitemap, GitHub, raw text or HTML.

Returns: The Markdown.

save_docs
url out_dir crawl max_pages js force single_file

Same extraction, written to files on disk.

Returns: The paths written.

detect_source_type
url

Which strategy a URL would use — a cheap probe, no extraction.

Returns: llms_txt, openapi, sitemap, github, raw_text or html.

READ BACK
search_knowledge_base
query technology version limit kind

Ranked search across every stored page at once.

Returns: Matches with a snippet showing why each page matched.

read_knowledge_base
name section version

Reads stored docs back; with section, only the matching pages, ranked.

Returns: The pages, newest version unless one is named.

list_knowledge_base
—

What has been harvested, which versions, and any harvest still running.

Returns: The inventory, with completeness per version.

forget_resolution
name

Forgets where a name resolved to. Deletes no documentation.

Returns: Confirmation.

forget_selection
name

Forgets which corpora were chosen, so it asks again. Deletes no documentation.

Returns: Confirmation.

OPT-IN forget_documentation

forget_documentation also exists, behind DOCSFORGE_ALLOW_DELETE=1. Deleting a harvest is the one irreversible thing here, and a model that has just mis-resolved a name is not the caller you want holding that lever.

A long harvest does not block

A call returns whatever is ready by a deadline — 25 seconds by default. A harvest that finishes inside it returns exactly what it always did. One that does not keeps running in the background, and the result says so:

harvest_response
>Currently harvesting 36/813 pages, 25s elapsed. This returned before the harvest finished so your client would not time out; it continues in the background while this server runs.
