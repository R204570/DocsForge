How it works

01

Resolve

Asks the package registries — npm, PyPI, crates.io, all keyless — where the library declares its documentation, then probes the site for an llms.txt or a docs root.

02

Verify

A page must name the package repeatedly before it is trusted. If nothing verifies, DocsForge says so and asks for a URL instead of picking something plausible.

03

Harvest

Best strategy first: llms-full.txt, then a docs-scoped sitemap, then a scoped crawl. Every page lands as Markdown, versions kept apart, incompleteness reported — never hidden.

Every source type, detected automatically

llms.txt / llms-full.txt OpenAPI / Swagger sitemap.xml GitHub repositories HTML docs & raw Markdown

The URL and, when needed, the content decide the strategy. You never pick.

Honest about coverage

A third of a manual that looks whole produces confident, wrong answers. So a partial harvest says so — in the harvest result, in list_knowledge_base, and again every time the content is read.
